Unidad 1: Clases y Objetos

Concepto

En Java, una clase es un molde que define las propiedades (atributos) y comportamientos (métodos) que tendrán los objetos. Un objeto es una instancia concreta creada a partir de ese molde usando la palabra clave new.

Ejemplo práctico en Java

public class Perro {
    String nombre;
    String raza;

    public void ladrar() {
        System.out.println(nombre + " está ladrando: ¡Guau guau!");
    }

    public static void main(String[] args) {
        Perro miPerro = new Perro();
        miPerro.nombre = "Firulais";
        miPerro.raza = "Golden Retriever";
        miPerro.ladrar();
    }
}

Ejercicio Práctico

Crea una clase llamada Libro que tenga dos atributos de tipo String: titulo y autor. Añade un método mostrarInfo() que imprima ambos datos en consola. En el método main, crea un objeto de la clase Libro, asigna valores y llama al método.

Solución sugerida:

public class Libro {
    String titulo;
    String autor;

    public void mostrarInfo() {
        System.out.println("Título: " + titulo + " | Autor: " + autor);
    }

    public static void main(String[] args) {
        Libro miLibro = new Libro();
        miLibro.titulo = "Cien años de soledad";
        miLibro.autor = "Gabriel García Márquez";
        miLibro.mostrarInfo();
    }
}

Unidad 2: Encapsulamiento

Concepto

El encapsulamiento protege los datos internos de una clase declarando sus atributos como private. Para interactuar con ellos de forma segura, se usan métodos públicos conocidos como Getters y Setters.

Ejemplo práctico en Java

public class CuentaBancaria {
    private double saldo;

    public void setSaldo(double m) {
        if (m >= 0) {
            saldo = m;
        } else {
            System.out.println("Error: Saldo negativo.");
        }
    }

    public double getSaldo() {
        return saldo;
    }

    public static void main(String[] args) {
        CuentaBancaria cuenta = new CuentaBancaria();
        cuenta.setSaldo(1500.50);
        System.out.println("Saldo actual: $" + cuenta.getSaldo());
    }
}

Ejercicio Práctico

Crea una clase Persona con un atributo privado int edad. Implementa un método setEdad(int e) que valide que la edad sea mayor o igual a 0 (si es menor, muestra error) y el método getEdad().

Solución sugerida:

public class Persona {
    private int edad;

    public void setEdad(int e) {
        if (e >= 0) {
            edad = e;
        } else {
            System.out.println("Error: La edad no puede ser negativa.");
        }
    }

    public int getEdad() {
        return edad;
    }

    public static void main(String[] args) {
        Persona p = new Persona();
        p.setEdad(25);
        System.out.println("La edad es: " + p.getEdad());
    }
}

Unidad 3: Herencia

Concepto

La herencia permite que una clase nueva (hija) adquiera atributos y métodos de una existente (padre) usando la palabra clave extends.

Ejemplo práctico en Java

class Vehiculo {
    String marca;
    public void mostrarMarca() {
        System.out.println("Marca: " + marca);
    }
}

public class Auto extends Vehiculo {
    int puertas;
    public void mostrarAuto() {
        System.out.println("Tiene " + puertas + " puertas.");
    }

    public static void main(String[] args) {
        Auto miAuto = new Auto();
        miAuto.marca = "Toyota";
        miAuto.puertas = 4;
        miAuto.mostrarMarca();
        miAuto.mostrarAuto();
    }
}

Ejercicio Práctico

Crea una clase base Empleado con el atributo String nombre y un método trabajar(). Crea una clase derivada Gerente que extienda de Empleado, agregue el atributo String departamento y un método organizar().

Solución sugerida:

class Empleado {
    String nombre;
    public void trabajar() {
        System.out.println(nombre + " está trabajando.");
    }
}

public class Gerente extends Empleado {
    String departamento;
    public void organizar() {
        System.out.println(nombre + " organiza el departamento de " + departamento + ".");
    }

    public static void main(String[] args) {
        Gerente g = new Gerente();
        g.nombre = "Carlos";
        g.departamento = "Sistemas";
        g.trabajar();
        g.organizar();
    }
}

Unidad 4: Polimorfismo

Concepto

El polimorfismo permite que objetos de diferentes subclases respondan a una misma invocación de método de forma específica mediante la sobrescritura (anotación @Override).

Ejemplo práctico en Java

class Animal {
    public void hacerSonido() {
        System.out.println("Sonido genérico.");
    }
}

class Gato extends Animal {
    @Override
    public void hacerSonido() {
        System.out.println("El gato dice: ¡Miau!");
    }
}

public class TestPolimorfismo {
    public static void main(String[] args) {
        Animal miAnimal = new Gato();
        miAnimal.hacerSonido();
    }
}

Ejercicio Práctico

Crea una clase base Figura con un método void dibujar(). Crea una clase derivada Circulo que extienda de Figura y sobrescriba dibujar() usando @Override.

Solución sugerida:

class Figura {
    public void dibujar() {
        System.out.println("Dibujando figura genérica.");
    }
}

class Circulo extends Figura {
    @Override
    public void dibujar() {
        System.out.println("Dibujando un Círculo.");
    }
}

public class TestFigura {
    public static void main(String[] args) {
        Figura f = new Circulo();
        f.dibujar();
    }
}
